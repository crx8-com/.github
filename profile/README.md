### ✨ 关于 CRX8 (About CRX8)

[CRX8.com](https://crx8.com) 致力于为全球浏览器用户与开发者提供：
- 🔍 **精选 Chrome 扩展下载与测评**：严选高生产力、实用无广告的优质浏览器插件（Chrome, Edge, Brave, Arc 兼容）。
- 🛡️ **安全与透明度**：倡导扩展开源化（Open-source Browser Extensions），提供透明的代码审查与 Manifest V3 现代规范参考。
- ⚡ **自动化持续集成**：探索浏览器扩展双平台（Chrome Web Store & Microsoft Edge Add-ons）从代码到应用商店的自动化发布实践。
