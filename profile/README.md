### ✨ About CRX8

[CRX8.com](https://crx8.com) provides web enthusiasts, power users, and developers with:
- 🔍 **Curated Chrome & Edge Extensions**: Handpicked extensions with high productivity, no bloatware, and verified compatibility (Chrome, Edge, Brave, Arc, Opera).
- 🛡️ **Open-Source Transparency**: We advocate open-source browser extensions (Manifest V3) with auditable code and strict privacy commitments.
- ⚡ **Automated CI/CD**: Seamless end-to-end publishing pipelines from Git commits directly to Chrome Web Store and Microsoft Edge Add-ons.
